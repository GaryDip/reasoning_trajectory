# 2026-07-19 周报:多跳检索 Gate 信号融合方法

## 一、背景

多跳问答（multi-hop QA）系统在回答一个问题时，需要分解成若干子问题（hop），逐跳检索证据、
逐跳作答，最终基于所有中间结果生成答案。一个 K-hop 问题对应 K 次检索：每一跳先用当前子问题
的 embedding 做一次余弦相似度检索，得到候选证据段落集合，再从中选出一个作为该跳的证据，
拼接进推理前缀，继续下一跳。

由于每一跳的检索都可能选错证据（余弦相似度最高的段落不一定是正确证据），系统引入一个轻量
分类器（下称 "gate"）：在这一跳选定证据、拼接进前缀之后，用 LLM（Llama-3.1-8B-Instruct）对
"前缀 + 该跳子问题 + 候选证据" 这段文本做一次前向传播，取某一层最后一个 token 的隐藏状态，
训练一个分类器判断"这一跳的证据选择是否有误"。gate 的输出可以用于两种方式：(a) 作为触发信号，
超过阈值则触发重新检索；(b) 作为连续分数，与余弦相似度加权混合，直接参与候选排序。生产链路
（`retrieval/run_retrieval_exp_wavefront.py`）采用方式 (b)，公式为：

```
final_score = emb_score - λ · gate_score
```

其中 `emb_score` 是候选与子问题的余弦相似度，`gate_score` 是 gate 对该候选打出的"证据选择
有误"概率，λ 是固定权重（默认 0.25）。

本周的工作围绕一个问题展开：LLM 前向传播中可以提取出**两种不同性质**的信号来训练 gate，
这两种信号此前分别独立验证有效，本周测试了将它们组合起来的多种方法。

## 二、两个独立信号

### 2.1 局部变化信号 Δ（gate v2）

对于第 j 跳，取"选定证据前"的前缀隐藏状态 `h_{j-1}` 和"选定证据后"的前缀隐藏状态 `h_j`，
定义 `Δ_j = h_j - h_{j-1}`，代表"这一步证据选择让模型内部状态产生了多大变化"。训练数据来自
按 (K, hop) 分桶采样的 gold/counterfactual trace 对（`hidden_states/pilot_multilayer`），
每个池化的 j（j=0..3，对应跨不同 K 值语义相同的跳位置）单独训练一个 `PCA(64) + Logistic
Regression` 模型。层的选择经过实验验证：j=0,1 使用第 15 层，j=2,3 使用第 23 层。

在 musique dev 全量 2417 条上端到端评测（检索+生成，`--beam-width 1`），四项指标：hop 级
recall@1、chain（一个问题的所有跳全部检索正确的比例）、答案 EM、答案 F1：

| 方法 | recall@1 | chain | EM | F1 |
|---|---|---|---|---|
| baseline（不使用 gate，纯余弦排序） | 0.6513 | 0.4233 | 0.4079 | 0.5012 |
| gate v2（Δ，连续加权混合） | 0.6627 | 0.4357 | 0.4100 | 0.5045 |

### 2.2 累计状态信号 h_after（probe）

与 Δ 不同，另一种信号只取"选定证据后"的绝对隐藏状态 `h_after`（不做差分），代表"截至当前
这一跳为止，整条推理前缀的状态"。训练数据额外抽取了每条 trace **每一个中间前缀位置**的隐藏
状态（不只是最后一跳），固定使用第 31 层，训练一个 `PCA(64) + Logistic Regression` 模型
（`error_propagation_probe/probe_artifacts`）。

同样在 musique dev 全量上评测，采用 `emb_score - 0.25 · probe_score` 的加权混合公式：

| 方法 | chain | EM | F1 |
|---|---|---|---|
| probe（h_after，加权混合） | 0.4659 | 0.393 | 0.4816 |

检索侧指标优于 baseline，但答案侧 EM/F1 未能超过 baseline，说明该信号单独使用时对最终答案的
帮助有限。

Δ 是**局部**信号（这一步本身变化大不大），h_after 是**全局**信号（截至目前状态整体是否正常）。
对两者的错例做重叠分析（按 id 对齐 2417 个样例）显示：两个信号"只有一方做对"的样例占比约
13%-14%，属于非冗余的互补覆盖，理想情况下若能完美择优，EM 上限可达 47.3%（单独使用任一信号
约 39%-41%），说明两个信号存在组合的价值。

## 三、组合方法一:检索前上下文条件化权重（未采用）

第一种组合思路：训练一个小型网络，根据"检索发生前"已知的上下文（主问题 embedding、检索前的
前缀隐藏状态、当前子问题 embedding）预测一个 [0,1] 的混合系数，决定这一跳整体上更该相信余弦
相似度还是更该相信 gate 分数。该网络的关键结构限制是：预测出的混合系数是**整跳级别**的——同一
跳里所有候选证据共享同一个系数，模型在训练时无法感知"具体选中了哪个候选"，只能对整跳给出一个
笼统判断。

在 dev 上以候选池内 gold 排名（recall@1/recall@3/mrr）作为离线评测指标（不涉及生成）：

| | recall@1 | recall@3 | mrr |
|---|---|---|---|
| 纯余弦相似度 | 0.8067 | 0.9396 | 0.8778 |
| 固定 λ=0.25（生产默认公式） | 0.8601 | 0.9635 | 0.9145 |
| 学出来的整跳级权重 | 0.8042 | 0.9318 | 0.8736 |

学出来的权重未能超过固定权重方案，且训练过程中出现了权重收敛到边界常数值的现象——由于混合
系数是整跳共享的，训练目标退化为"整体上该多信哪一方"这一单一判断，缺乏候选级别的区分信号，
容易被训练目标推向极端值而非有信息量的中间值。基于此，认为"检索前上下文、整跳共享权重"这一
结构设计存在局限，未采用。

## 四、组合方法二:固定/启发式权重的后融合

后融合指 gate v2 与 probe 各自独立训练、独立打分，仅在推理阶段组合两者的输出分数，不涉及
联合训练。

### 4.1 三种投票方式（`combined_gate_rerank`）

两个信号在同一次批量前向传播中一并打分（union of layers：gate v2 所需的 {15, 23} 与 probe
所需的 {31}，共享一次 Llama 前向计算），组合方式：

- **sum**：`final = emb_score - λ_1 · gate_v2_score - λ_2 · probe_score`，λ_1=λ_2=0.25
- **veto**：任一模型判定候选异常（概率 > 0.5）则否决该候选，剩余候选按余弦相似度排序
- **rrf**：gate v2 与 probe 各自独立完成一次完整重排后，融合两者的**名次**（Reciprocal Rank
  Fusion：`1/(k+rank_1) + 1/(k+rank_2)`，k=60），不比较原始分数幅度

musique dev 全量端到端结果：

| 方法 | recall@1 | chain | EM | F1 |
|---|---|---|---|---|
| sum | 0.6869 | 0.4894 | 0.4141 | 0.5089 |
| rrf | 0.6705 | 0.4564 | 0.3922 | 0.4822 |
| veto | 未见提升 | — | — | — |

sum 是三种方式中唯一同时超过 gate v2、probe 单独使用结果的方案。为验证 sum 带来的提升是否为
真正的互补（而非单纯"偏向更强的一方"），统计了 gate v2 与 probe 各自"独有正确"样例的保留率、
以及"两者皆错"样例的修复率：两个信号独有正确样例的保留率分别为 47.2%（仅 gate v2 对）和
78.1%（仅 probe 对），且在两者皆错的 1186 个样例中，sum 修复了 4.9%（约 58 个）——这部分样例
单独使用任一信号都无法得到正确结果，只有组合后才能修复，确认存在真实的互补效应。

### 4.2 更精细的启发式权重

在 sum 基础上尝试了三种进一步细化权重的方式，评测均基于同一份真实检索候选池数据
（`adaptive_lambda_rerank` 构建的候选池，含每候选的余弦分数、gate_v2 分数、probe 分数），
指标为候选池内 gold 排名 recall@1：

- **置信度加权**：按池内打分标准差动态分配权重（标准差越大代表该信号本次判断越果断）
- **粗筛精排**：先用 probe 分数筛出 top-k 候选，再用 gate v2 分数在候选中重排
- **网格搜索**：独立扫描 (λ_gate_v2, λ_probe) 组合

| 方法 | recall@1 |
|---|---|
| sum（固定 0.25/0.25） | 0.8660 |
| 置信度加权 | 0.8646 |
| 粗筛精排（k=3） | 0.8643 |
| 网格搜索最优（0.25, 0.10） | 0.8690 |

网格搜索找到的配置在整体 recall@1 上略高于 sum，但对该配置做互补性分析发现：probe 独有正确
样例的保留率降至 50.6%（sum 为 72.1%），两者皆错样例的修复率降至 1.5%（sum 为 5.5%）——该配置
是以牺牲互补性为代价换取整体数字提升，与两个信号"各自发挥独特贡献"的目标不符。

进一步测试了三方凸组合（余弦、probe、gate_v2 三者权重之和为 1，各自 z-score 后组合）：整体
recall@1 最优配置为 (0.6, 0.2, 0.2) → 0.8679；均等三分配置 (0.33, 0.33, 0.33) → 0.8463
（整体数字更低），但两者皆错样例的修复率达到 16.0%（远高于其他配置）。这一系列实验显示同一个
规律：**越偏向整体准确率最大化的权重配置，互补修复率越低；权重越均衡，互补修复率越高但整体
数字下降**——所有后融合方法目前都停留在这一权衡曲线上，未能同时改善两个指标。

## 五、特征层面融合（gate v3）

前述所有方法均为后融合：gate v2 与 probe 各自独立训练，推理时组合两者**输出的分数**。gate v3
改为特征层面融合：不训练两个独立模型，而是将同一跳的 `h_after`（probe 的原始特征）与 `Δ_j`
（gate v2 的原始特征）各自独立做 PCA（两者协方差结构不同，不共用同一个 PCA），将降维后的两组
特征拼接，训练**一个** Logistic Regression：

```
p_j = σ(w_h^T PCA(h_after) + w_Δ^T PCA(Δ_j) + b)
```

层的选择沿用 gate v2 已验证的分层结果（j=0,1→第 15 层，j=2,3→第 23 层），训练数据复用已提取
的 `hidden_states/pilot_multilayer`，无需新的隐藏状态提取。

### 5.1 分类指标评测

在与 gate v2 相同的评测协议（固定 gold/counterfactual trace 数据，判断"该跳证据选择是否有
误"的二分类任务）下对比：

| | AUC | 整体 F1 | 整体 TPR |
|---|---|---|---|
| gate v2（Δ only） | 0.9221 | 0.7785 | 0.8456 |
| gate v3（h_after ⊕ Δ） | 0.9357 | 0.793 | 0.8838 |

按跳位置拆分，j=2（gate v2 原本最弱的一跳）F1 提升幅度最大（0.7535 → 0.7919）。

### 5.2 端到端评测

musique dev 全量，公式沿用 `final_score = emb_score - λ · gate_v3_score`（λ=0.25，与 gate v2
的公式结构一致，仅将单一 Δ 分数替换为拼接特征打出的分数）：

| 方法 | recall@1 | chain | EM | F1 |
|---|---|---|---|---|
| gate v2（Δ only） | 0.6627 | 0.4357 | 0.4100 | 0.5045 |
| gate v3（h_after ⊕ Δ） | 0.6950 | 0.5010 | 0.4224 | 0.5146 |

四项指标全面优于 gate v2，其中 chain 提升幅度最大（+6.5 个百分点），与分类指标上 j=2 提升
最多的结果一致：链路越长，单跳弱点被放大得越明显，改善最弱的一跳对整条链路正确率的影响最大。

## 六、学习型逐候选门控（context gate）

第三节的组合方法失败的结构性原因是"权重按整跳共享，看不到具体候选"。本节测试将同一思路重新
设计为**候选级别**的权重：对每个候选证据，用**该候选自身**选定后的 `h_after`（而非检索前的
上下文）计算一个混合系数：

```
α_i       = σ(w^T PCA(h_after)_i + b)              # 每个候选各自计算
anomaly_i = α_i · gate_v2_score_i + (1 - α_i) · probe_score_i
final_i   = emb_score_i - 0.5 · anomaly_i           # 0.5 = sum 方案的 λ_1+λ_2 固定预算
```

由于同一跳中不同候选拼接的证据文本不同，各自的 `h_after` 也不同，因而 α 可以在同一候选池内
取不同值，训练时具备候选级别的区分信号——这是与第三节方法的核心区别。模型结构为单层线性映射
加 sigmoid（65 个参数），训练标签为候选池内 gold 排名的 listwise 交叉熵损失。所需的候选级
`h_after`（PCA 投影至 64 维，复用 probe 的 PCA 与第 31 层）通过对已有候选池数据补充提取得到，
无需额外的 Llama 前向计算之外的新数据。

### 6.1 离线候选池排序评测

与第四节相同的候选池 recall@1 指标：

| 方法 | recall@1 | 两个信号皆错时的修复率 |
|---|---|---|
| sum（固定 0.25/0.25） | 0.8660 | 5.5% |
| context gate（逐候选学习权重） | 0.8776 | 16.4% |

学出的 α 分布均值 0.5593、标准差 0.4636，覆盖 0 到 1 的完整区间，未出现坍缩为常数的现象。
该结果在整体 recall@1 和互补修复率两项指标上同时优于此前所有后融合方法，是本周唯一一次未
出现"整体准确率与互补性此消彼长"权衡的组合方案。

### 6.2 端到端评测

musique dev 全量：

| 方法 | recall@1 | chain | EM | F1 |
|---|---|---|---|---|
| gate v3 | 0.6950 | 0.5010 | 0.4224 | 0.5146 |
| context gate | 0.7018 | 0.5184 | 0.4208 | 0.5147 |

检索侧指标（recall@1、chain）优于 gate v3，chain 提升 1.74 个百分点，是本周所有方案中的最高
值；答案侧指标（EM、F1）与 gate v3 基本持平，EM 略低 0.16 个百分点（在噪声范围内）。检索侧的
提升未能完全转化为答案侧的提升，可能与最终阅读理解模块本身的能力上限有关（EM 采用严格字符串
匹配）。

## 七、结果汇总

端到端评测（musique dev 全量，`--beam-width 1`，四项指标口径一致）：

| 方法 | recall@1 | chain | EM | F1 |
|---|---|---|---|---|
| baseline | 0.6513 | 0.4233 | 0.4079 | 0.5012 |
| gate v2（Δ） | 0.6627 | 0.4357 | 0.4100 | 0.5045 |
| probe（h_after） | — | 0.4659 | 0.393 | 0.4816 |
| 后融合 sum（gate v2 + probe，固定权重） | 0.6869 | 0.4894 | 0.4141 | 0.5089 |
| 后融合 rrf | 0.6705 | 0.4564 | 0.3922 | 0.4822 |
| **gate v3（特征层面融合）** | 0.6950 | 0.5010 | **0.4224** | 0.5146 |
| **context gate（逐候选学习权重）** | **0.7018** | **0.5184** | 0.4208 | **0.5147** |

gate v3 与 context gate 端到端效果接近：gate v3 答案侧指标略高，context gate 检索侧指标更高。
在效果接近的前提下，gate v3 结构更简单（单一 Logistic Regression，复用已验证的层选择，
训练流程为一次 sklearn 拟合），不需要额外训练一个神经网络门控模块；context gate 需要维护
gate v2、probe、以及独立训练的门控网络三个组件，整体流程更复杂。综合两方面因素，当前采用
gate v3 作为默认方案，context gate 作为已验证过的备选方案保留。
