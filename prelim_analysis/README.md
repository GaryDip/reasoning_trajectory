# Preliminary analyses — 代码、结果与每张图的解释

把 `PRELIM_ANALYSIS_PLAN.md` 里的四个早期探索实验按**最终口径**重做，用于论文第 4 章
"Preliminary Analysis"（主结果之前）与第 5 章的补充证据。

**最终口径**：Llama-3.1-8B-Instruct、**第 15 层**、最终序列化格式
`Question: Q Step 1: q₁ Evidence: "e₁" …`（证据只放段落正文、不放标题，**不含 Final Answer**），
每个累积前缀单独套 chat template（一个完整 user turn，`add_generation_prompt=False`），
读最后一个 token（end-of-turn）的隐状态。

**图的规格**：正文宽 16 cm，字号 8 pt，图内文字全英文，300 dpi。

### 两个容易踩的坑（已写进 `common.py` 的 docstring）

1. **`hidden` 的轴顺序是 `(层, 前缀, 4096)`，不是 `(前缀, 层, 4096)`**。K=3 的链恰好 4 层 4 前缀，
   取错了也不会报错，只会悄悄拿到错的向量。
2. **`trace_pos` 是 1-indexed**：prefix 1 = 只有问题，prefix p = 第 p−1 步之后，最大 K+1。
   计划书里写的 pos 0..K 对应这里的 prefix 1..K+1。文档与图里统一用 "prefix index"。

另外：gold 链存全部 K+1 个前缀；**反事实链在注入跳处截断**（`n_take = h+1`），所以替换进来的段落
第一次出现在前缀里的位置就是它的**最后一个**前缀，`trace_pos = h+1`。

## 2. 实验 1：正确链上的步骤几何

### 数据与做法

`train_pilot` 里 `trace_type=correct` 的 gold 链（MuSiQue 训练集、GT 分解 + 标注证据），第 15 层。
每个 K 随机抽 1,000 条链，取它们的**全部前缀**。4096 维 → PCA 50 维 → t-SNE
（perplexity 30、`init="pca"`、seed 0、1000 轮）。

### 图 `exp1_step_geometry_by_K.png`（主图）

三个面板，**按链长 K 分面**：

| 面板 | 点数 | 构成 |
|---|---|---|
| K=2 | 3,000 | 1,000 条链 × 3 个前缀 |
| K=3 | 4,000 | 1,000 条链 × 4 个前缀 |
| K=4 | 5,000 | 1,000 条链 × 5 个前缀 |

颜色 = prefix index。坐标轴无刻度（t-SNE 坐标没有量纲意义）。

**结果**：每个面板内部，所有 prefix index 各自成团。K=4 面板里 prefix 4（红）与 5（紫）最接近，
但仍可分辨。

**为什么要分面**（这是对原实验的主要修正）：原图把三种 K 混在一起，结果 boundary 4 和 5 糊成一片。
但 **prefix 5 只可能来自 K=4 的题、prefix 4 只可能来自 K≥3 的题**——原图里「不同位置」同时意味着
「不同题目子集」，重叠是采样结构带来的，不是表示的性质。分面之后同一面板里所有位置来自同一批
1,000 道题，这个混淆消失。

### 图 `exp1_step_geometry_pooled.png`（附图，对照原截图）

三种 K 的点混在一起，每个 prefix index 等量抽样：prefix 1/2/3 各 2,400，prefix 4 为 2,000，
prefix 5 只有 1,000（只有 K=4 的链有），共 10,200 点。

**结果**：完整复现原截图——prefix 1/2/3 分离，**4 与 5 大面积重叠**。保留它是为了说明
「原来的观察是真实的，但成因是采样结构」。

### 定量指标（`results/exp1_step_geometry.json`）

t-SNE 只是示意，不能当证据。另算 **10-NN 纯度**：在 PCA-50 空间里按**题目 id** 切 80% 参考 /
20% 查询（保证同一道题的不同前缀不会互相「作弊」），每个查询点取 10 个最近邻，统计其中与它
prefix index 相同的比例。

| K | 10-NN 纯度 | 随机水平 |
|---|---|---|
| 2 | **0.9995** | 0.3333 |
| 3 | **0.9790** | 0.2500 |
| 4 | **0.9747** | 0.2000 |

**图注必须写明的已知混淆**：前缀文本长度随 prefix index 单调增长，且 index 在文本里是显式可见的
（`Step 1:`、`Step 2:` …）。这两点在实验 2 里被量化。

## 3. 实验 2：位置探针

### 数据与做法

训练用 `train_pilot` 的 gold 链（K=2/3 各抽 4,000 条，K=4 只有 2,023 条全取），测试用 **dev 全量**
gold 链（1,252 / 760 / 405 条）。第 15 层。分类器为多类 logistic regression（标准化 + `C=1`、
`max_iter=2000`）。**dev 只用于报告，不参与任何超参选择**，与全文「超参不依赖 dev」的口径一致。

### 图 `exp2_prefix_index_confusion.png`

三个混淆矩阵，纵轴 = 真实 prefix index，横轴 = 预测 prefix index，格内为题数。
测试集大小：K=2 为 3,756 个前缀、K=3 为 3,040、K=4 为 2,025。

**结果**：

| K | 准确率 | 错误情况 |
|---|---|---|
| 2 | **1.0000** | 无 |
| 3 | **0.9990** | 3 个 prefix 4 判成 3 |
| 4 | **0.9852** | 27 个 prefix 4 判成 5、3 个 5 判成 4（相邻位置最易混） |

复现了原实验的 0.9967 / 1.0000 / 0.9970。

### 两个长度对照（在 json 里，不在图上）

**(a) 只用 token 数做同样的分类**（一维特征）：

| K | 隐状态 | 只用 token 数 | 多数类 |
|---|---|---|---|
| 2 | 1.0000 | 0.8698 | 0.3333 |
| 3 | 0.9990 | 0.8273 | 0.2500 |
| 4 | 0.9852 | 0.6765 | 0.2000 |

各 prefix index 的平均 token 数（K=4）：32.4 / 145.9 / 277.3 / 421.9 / 576.5。长度与位置强相关，
所以能到 0.68–0.87，但**明显低于隐状态**。

**(b) 在同一长度区间内再做一次**（按长度五分位切 5 档，档内训练档内测试）：
K=2 全部 1.00；K=3 为 1.00 / 0.998 / 0.998 / 0.974；K=4 为 0.998 / 0.985 / 0.958 / 0.966。
**长度被控制住之后探针照样接近完美，所以长度不是解释。**

### 这个结果能支持什么、不能支持什么

探针读的是隐状态、从不接触文本，所以高准确率**是**一个关于表示的事实陈述：第 15 层的前缀状态
**线性编码了步骤位置**。但它区分不了两个假设，因为两者都预测 ~100%：

- **H1**：每一步有自己的推理几何（不同跳因推理内容不同而占据不同区域）；
- **H2**：状态里有一个**表面计数器**——位置是文本里 `Step N:` 个数的确定性函数，而且最后一个
  `Step k:` 的 k 就是答案。

**用现有数据无法区分**（换层、分长度箱、跨 K 迁移，H2 都同样预测高准确率）。判别性测试需要改变
**输入**：把 `Step N:` 同质化成 `Step:` 后重新提取隐状态（约 2–3h GPU，未做）。

因此论文里应写成「状态线性编码前缀位置」，**不写**「每一步有自己的推理分布」。

### 图 `exp2_chain_length_probe.png`（新增的干净探针）

- **只取 prefix 1 的状态**——模型只读了问题、还没有任何 `Step` 标记
- 目标是**这道题需要几跳 K**（3 类）
- 训练 10,023 个样本（train），测试 2,417 个（dev 全量）
- 图为 3×3 混淆矩阵，格内为题数

**结果**：准确率 **0.7617**，多数类基线 **0.5180**。对角线 1146 / 497 / 198，错误几乎全在相邻类。

**为什么这个探针干净**：prefix 1 的文本里没有任何关于跳数的线索（就是一个问句），所以不受 H2 影响。
按 K 拆开后与 BART 分解器对比：

| 真实 K | 探针（线性读出） | BART 分解器（WORK_SUMMARY 3.8） |
|---|---|---|
| 2 | 1146/1252 = 0.915 | 0.982 |
| 3 | 497/760 = 0.654 | 0.782 |
| 4 | 198/405 = **0.489** | **0.489** |

**4 跳题上两者数值完全相同，退化模式也一致。** 这说明「4 跳分解是瓶颈」不只是分解器训练数据的
问题——在问题的表示层面，跳数本身就难判断。对 WORK_SUMMARY 3.8 的结论是一个表示层面的佐证。

## 4. 实验 3：同一位置上正确证据 vs 错误证据

### 数据与做法

`dev` split。每个 (K, 注入跳 h) 格子里，取**同一道题**的 gold 链与反事实链在**同一个
prefix index = h+1** 处的状态（h+1 是替换段落第一次进入前缀的位置）。每格 400 对，共 9 格。
第 15 层。dev 可用对数为每格 405–1,252，训练集可到 2,023–14,376（原实验是 100–150 对）。

### 图 `exp3_shift_projection.png`（主图，信息量最大）

构造方式：

1. 把该格的 400 对**随机劈成两半**；
2. 在**前一半**上算方向 `w = mean(替换状态) − mean(金标状态)`，归一化；
3. 在**留出的后一半**上把每个状态投影到 `w` 上，得到一个标量分数；
4. 画两个直方图：蓝 = 金标证据，红 = 替换证据；
5. 标题里的 AUC 是这个一维分数的 ROC-AUC，**在留出半数上算的**。

**结果**：九个格子全部清晰分离。

| 格子 | 留出 AUC | 格子 | 留出 AUC |
|---|---|---|---|
| K=2 hop 1 | **0.9268** | K=4 hop 1 | 0.9105 |
| K=2 hop 2 | 0.9034 | K=4 hop 2 | 0.8951 |
| K=3 hop 1 | 0.8933 | K=4 hop 3 | 0.8970 |
| K=3 hop 2 | 0.8956 | K=4 hop 4 | **0.9179** |
| K=3 hop 3 | 0.9157 | | |

**一个线性方向——连分类器都算不上，就是两组的均值差——就能把「这一跳的证据对不对」分开，
AUC 0.89–0.93**，已接近完整 gate 的 h-only 留出 AUC 0.9345（WORK_SUMMARY 1.4）。这是「用隐状态
偏移判断召回对不对」这个想法最直接的证据，也解释了为什么 gate 用 PCA+LR 这种简单结构就够。

### 图 `exp3_evidence_shift_by_cell.png`（定性图）

每个面板只画**一个 (K, h) 格子**：400 个金标状态（蓝点）+ 400 个替换状态（红叉），共 800 点，
PCA-50 → t-SNE。**位置在面板内被固定**，所以图上只剩「金标 vs 替换」一个因素。

**结果**：九个格子都能看到蓝红分区（不是完美分开，与 AUC≈0.9 一致）。

**对原实验的修正**：原图把多个 prefix index 画在同一张 t-SNE 上，**位置的方差完全压过了替换造成的
偏移**，结果图上分开的是颜色（位置）而不是形状（正/负），等于重复展示了实验 1。把位置固定住，
对比立刻显出来。

> 实现细节：`marker="x"` 是纯描边标记，`linewidths=0` 会导致**什么都画不出来**（第一版就是这么
> 丢了全部红点）。现在用 `linewidths=0.45`。

### 图 `exp3_shift_distances.png`（尺度参照）

每个 (K,h) 格子两根柱子：

- **红柱** = 同一道题的金标状态 ↔ 它的替换版本，余弦距离均值；
- **灰柱** = 同一位置上**两道不同题**的金标状态之间的余弦距离（随机配对）。

**结果**：红柱 0.142–0.178，灰柱 0.161–0.217，**红柱始终比灰柱矮**，比值 0.728–0.917。

**这张图说明的是尺度，不是因果**：替换证据造成的位移**小于**两道不同题之间的距离——这正好量化了
为什么在混合了不同题、不同位置的 t-SNE 上看不见它。

> 计划书原本把灰柱当「对照」，这里改称**尺度参照**：两道不同的题问题、证据、长度全不一样，距离大
> 是必然，它不能支持「位移与正确性有关」。支持那一点的是上面的留出 AUC。
> 若要一个真正的对照，应当是「同题、同位置、换成本题**另一篇 gold** 段落」——文本同样变了但前缀
> 仍然全是标注证据。那需要新提取隐状态（约 1h GPU，未做）。

## 5. 实验 4：自然错误相对「正确转移」参考分布的偏离

实验 1–3 用的都是**构造的错误**。实验 4 问：系统自己犯错时，同样的信号还在不在。

### 第 1 步：重建自然错误的链（`exp4_build_traces.py`）

- 读 λ=0 无 gate run（`retrieval/results/20261003_070503_nogate_musique_lambda0_dev`）的逐题日志，
  取每题**实际选中的段落 id** 和逐跳短答案；
- 与 MuSiQue 标注比对，**选中段落 ≠ 标注段落**的跳即为错；
- 只保留 BART 预测跳数 == 标注跳数的题（否则跳对不齐）：**2,022 / 2,417 题（83.7%）**；
- 其中 **834 条一跳没错（control 组）**、1,188 条至少错一跳；按错误跳数分别为
  0 错 834、1 错 740、2 错 332、3 错 105、4 错 11；
- 按最终格式序列化成 trace jsonl。

> **为什么写 `trace_type="correct"`**：提取脚本会把标为 `"error"` 的链在注入跳处截断
> （`n_take = wrong_hop + 1`），而这里需要**错误之后的转移**，不能截断。真实的错误跳记在
> `wrong_hops` 字段里，提取脚本会原样写进 npz。

### 第 2 步：提取隐状态（唯一需要 GPU 的一步，约 2 分钟）

2,022 条链 × 3–5 个前缀 ≈ 7,056 个前缀，第 15 层。

### 第 3 步：打分（`exp4_oracle_manifold.py`）

- **参考分布**：train 的 8,000 条 gold 链，对每个 (K, 转移 j) 收集
  **`Δ_j = h_j − h_{j−1}`**（生产定义；计划书写的 `h_j − u_j` 是笔误），PCA 降到 40 维，
  再用 Ledoit-Wolf 估均值与协方差 → Mahalanobis 距离。
  参考分布自身的距离均值约 **6.2**、标准差 **0.85–1.12**（40 维卡方该有的样子）。
- **测试**：同样算 Δ、投到同一 PCA 空间、算 Mahalanobis、按参考的均值/标准差转成 z。
- 一条链若多跳错（如 `wrong_hops=[1,3]`），同时进 err_hop_1 与 err_hop_3 两组。
- **没有「→ Final Answer」那一列**：原图里它在每行都最大、control 行也有 0.53–1.36，主要测的是
  参考链与 pipeline 链的系统差异；本口径的前缀本来就不含最终答案，所以每一列都在吞入检索到的段落。

### 图 `exp4_oracle_manifold.png`（绝对 z，**不要直接用**）

每个 K 一张热图，行 = control / err_hop_1…err_hop_K，列 = Q→E1、E1→E2、…，格内为平均 z。

**问题**：control 行应该接近 0（它们是没出错的链），实际是 K=2 约 0.0、**K=3 为 −0.40/−0.65/−0.43、
K=4 为 −0.53 到 −1.10**。负数意味着这些链比参考链**更靠近**分布中心。这是系统性偏移：参考用
**GT 标注分解**的链，测试用 **BART 分解**的链，两者的 Δ 分布本身不同。原实验里 control 行同样非零
（方向相反，+0.5~1.1）。

### 图 `exp4_oracle_manifold_vs_control.png`（主图）

同样的热图，但每格**减掉同一列 control 行的值**，抵消上面那个偏移，剩下的是「出错比不出错多偏离
多少」。标题里标了每个 K 的 control 组样本数。

| | Q→E1 | E1→E2 | E2→E3 | E3→E4 |
|---|---|---|---|---|
| **K=2**（control n=609）err_hop_1 | +0.55 | **+0.96** | | |
| err_hop_2 | +0.12 | **+1.04** | | |
| **K=3**（control n=197）err_hop_1 | **+0.03** | +0.66 | +0.57 | |
| err_hop_2 | −0.02 | +0.72 | +0.52 | |
| err_hop_3 | −0.04 | +0.52 | +0.38 | |
| **K=4**（control n=**28**）err_hop_1 | +0.21 | +0.17 | +0.20 | +0.06 |
| err_hop_2 | +0.15 | +0.14 | −0.04 | −0.08 |
| err_hop_3 | +0.14 | +0.12 | −0.16 | −0.15 |
| err_hop_4 | +0.10 | +0.13 | −0.08 | −0.17 |

**三个结论**：

1. **K=2 / K=3 上错误组确实偏离更多**，量级 +0.4 ~ +1.0 个标准差。这是**自然错误**下的前缀污染
   证据，与 WORK_SUMMARY 3.10 在**构造错误**上的发现（错误之后选对的跳被抬高到 2.2–2.6 倍）
   方向一致，论文里可写 "consistent with"。

2. **`Q→E1` 这一列几乎没有偏离**——K=3 的 err_hop_1 只有 **+0.03**，而错误证据正是在这个转移里
   进入的；偏离出现在它**之后**的列（+0.66、+0.57）。这**复现了原热图里那个异常**
   （err_hop_1 在 Q→E1 上 z=−0.05）。
   与之对照，训练出来的 gate 在 j=0 这个转移上**判别力最强**（训练 AUC 0.9707、dev TPR 0.9338，
   WORK_SUMMARY 1.4）。合理解释是 Q→E1 的参考分布方差最大（从「只有问题」到「问题+第一步」，
   Δ 幅度本身最大），z 被稀释。
   **结论：无监督的流形距离远弱于训练出来的判别器**——这反过来支持「需要一个学出来的 gate」，
   比含糊地说「偏离变大」有价值。

3. **K=4 那一栏不要用**：control 组只有 **28 条链**（K=4 的 198 题里 170 题至少错一跳），
   差值在 ±0.2 内来回，区分不了信号与噪声。已标注在图上。
